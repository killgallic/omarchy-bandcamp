# Changelog

## 1.0.0 — 2026-09-28

First public release candidate. Adds a native Omarchy service, bar widget and player for a purchased Bandcamp collection; remembered login through Secret Service; queue and playlist controls; collection filters, favourites and hidden records; optional MusicBrainz tags; configurable appearance, scrolling and cache; offline collection browsing; and MPRIS media controls.

The install command keeps the Python runtime outside the plugin tree, allowing Omarchy source validation and updates. A user-scoped uninstall command removes app integration while preserving personal data. CI, package checks, release drafts and contributor documentation support public maintenance.
