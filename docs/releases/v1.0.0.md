Omarchy Bandcamp v1.0.0 brings a purchased Bandcamp collection into a native Omarchy player, with a bar widget, mini player, playlists, queue, media keys, collection filters, favourites, and optional MusicBrainz tags.

Install on Omarchy 4 with Quickshell:

```bash
sudo pacman -S --needed uv mpv libsecret
omarchy plugin add https://github.com/killgallic/omarchy-bandcamp.git --enable
~/.config/omarchy/plugins/killgallic.bandcamp/bin/setup
```

Open Bandcamp from Super+Space. Generate credentials in Bandcamp Fan Settings → Subsonic; the ordinary Bandcamp password is not used. For updates, run `omarchy plugin update killgallic.bandcamp` and rerun `bin/setup` in the plugin directory.

This release uses Bandcamp's beta Subsonic interface. Public discovery pages still open in a browser, and downloads are not implemented. See README for usage and limitations, CONTRIBUTING for local development, and SECURITY for private vulnerability reports.
